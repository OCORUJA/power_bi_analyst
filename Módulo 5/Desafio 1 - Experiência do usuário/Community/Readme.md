# Curso NTT Data - Engenharia de Dados com Python

Bem-vindo ao repositório do projeto desenvolvido para o curso NTT Data - Engenharia de Dados com Python, oferecido pela DIO. Este projeto tem como objetivo aprimorar a experiência do usuário ao visualizar um relatório, reorganizando as informações de forma intuitiva e esteticamente agradável.

## Descrição

O projeto consiste na reformulação de um relatório existente, com foco na redistribuição dos dados para facilitar a leitura e a compreensão pelo usuário. Para isso, foram aplicados conceitos como a proporção áurea, padronização de cores e botões de navegação, resultando em uma apresentação mais fluida e visualmente harmoniosa.

## Ferramentas Utilizadas

- **Power BI**: Plataforma usada para criar, visualizar e modelar os dados do relatório.

### Distribuição dos dados

Utilização de recursos do Power BI para otimizar a visualização gráfica.

Padronização de cores em gráficos e textos, evitando excesso e garantindo consistência.

Aplicação da proporção áurea para direcionar a atenção do usuário às informações mais relevantes.

Implementação de botões de navegação para facilitar a movimentação entre as páginas do relatório.
